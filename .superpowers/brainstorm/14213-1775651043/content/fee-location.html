Where should "Add New Fee" live?

The task describes custom fees with formulas, conditions, and loan applicability. Where should this feature be managed?

A

Inside Loan Product Form

Add an "Additional Fees" section below the current hardcoded fees (processing fee, service fee). Each product defines its own custom fees inline in the create/edit dialog.

Pros

  • Simple — everything in one place
  • No new pages needed

Cons

  • Fees can't be reused across products
  • Dialog becomes very long
  • Doesn't match task description ("applicable to which loans")
B

Separate Fee Management (Recommended)

A dedicated section (Settings > Fees) where you create fee templates with all the rules. Each fee selects which loan products it applies to via checkboxes. The loan product form shows linked fees as read-only.

Pros

  • Matches the task description exactly
  • Fees are reusable across multiple products
  • Clean separation of concerns
  • "Applicable to Which Loans" checkbox makes sense here

Cons

  • New page/route to build
  • Slightly more navigation for the user
