When "Formula" is selected, what should the input look like?

The task gives an example: "A/B x 3%, where A is Loan Amount and B is Term in Days"

A

Free-text Formula Input

A text field where the user types the formula directly, e.g. (loan_amount / term_days) * 0.03. Flexible but error-prone.

B

Structured Formula Builder

Dropdowns to pick variables (Loan Amount, Term in Days) and operator fields. Guided but limited to simple expressions like A / B × rate%.

C

Skip Formula for Now (Recommended)

Implement Fixed and Percentage types first. Add a "Formula" option as disabled/coming soon. The task also marks "Tiered Charges" as coming soon — formula could follow the same pattern. Keeps scope manageable.
