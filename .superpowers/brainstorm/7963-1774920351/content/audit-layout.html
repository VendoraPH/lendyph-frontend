Audit Trail Page Layout

How should the audit log page be structured?

A

Table with Filter Bar

Clean table layout with a horizontal filter bar at the top (date range, user, action type, module). Click a row to expand an inline detail panel showing before/after changes. Similar to your existing Users page pattern.

B

Table + Side Detail Panel

Same table but clicking a row opens a slide-out side panel (like email clients) showing full detail — user info, timestamp, action description, and before/after changes in a diff-style view. Filters stay in a collapsible sidebar on the left.

C

Timeline + Dialog Detail

Activity feed style with a vertical timeline. Each entry shows avatar, action, and timestamp. Click any entry to open a dialog/modal with full before/after change details. More visual but less data-dense.
